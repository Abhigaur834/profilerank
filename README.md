# ProfileRank

ProfileRank is a career-brand intelligence MVP that scores professional profiles, identifies high-impact gaps, and turns them into an actionable improvement plan.

## Included
- Responsive ProfileRank dashboard
- Local profile analyzer with explainable scoring
- Profile recommendations
- Resume readiness checker
- LinkedIn content idea studio
- 7-day action plan with local progress persistence
- Product specification and screen architecture in `PRODUCT_SPEC.md`

## Run locally
Open `index.html` in a browser. No build step is required.

## GitHub Pages
The app is static HTML/CSS/JS and can be published from the repository root on the `main` branch.

## Important MVP limitation
ProfileRank does not request LinkedIn credentials or scrape LinkedIn. The analyzer evaluates content the user pastes into the browser.
